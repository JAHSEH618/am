# AIWatch 安装使用教程

面向接手本项目的开发人员 / 运维，说明如何从源码构建、部署服务端、分发客户端，以及管理员与员工如何使用。

更完整的产品说明见 [README.md](../../README.md)，设计文档见 [docs/design/](../design/)。

---

## 1. 项目是什么

AIWatch 由两部分组成：


| 组件                 | 说明                                                   |
| ------------------ | ---------------------------------------------------- |
| **aiwatch-server** | Spring Boot 单体（内置 React 管理后台），负责数据入库、聚合、报告与配置        |
| **aiwatchd**       | 员工电脑上的 Go 客户端，采集 Cursor / Claude Code 等 AI 工具使用情况并上报 |


员工**不需要登录后台**；管理员通过浏览器登录后台查看数据，员工只需安装客户端。

---

## 2. 环境要求


| 项      | 要求                             |
| ------ | ------------------------------ |
| 服务端 OS | Linux / macOS（生产建议 Linux）      |
| JDK    | **17+**                        |
| MySQL  | **8.x**，字符集 `utf8mb4`          |
| 构建工具   | Gradle（项目自带 `server/gradlew`）  |
| 客户端构建  | Go **1.22+**（仅运维打分发包时需要）       |
| 网络     | 员工电脑能访问服务端 HTTP(S)；服务端能连 MySQL |


---

## 3. 数据库初始化

```bash
# 建库（按需改用户名密码）
mysql -uroot -p -e "CREATE DATABASE am CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 导入表结构 + 基础种子数据（幂等，可重复执行）
mysql -uroot -p am < server/src/main/resources/sql/schema.sql
```

`schema.sql` 已包含：

- 全部业务表 DDL
- `monitor_target` 字典（Cursor、Claude Code 等）
- `sys_config` 默认配置（含初始管理员账号，见下文）

生产环境 `**spring.sql.init.mode=never**`，必须手工执行上述 SQL，不能依赖应用自动建表。

---

## 4. 构建服务端

```bash
cd server
./gradlew clean bootJar
```

产物：

```text
server/build/libs/aiwatch-server-<版本号>.jar
```

Gradle 会自动编译前端并打入 jar 内的 `static/`，本机无需单独安装 Node/pnpm。

---

## 5. 构建客户端分发包

客户端二进制**不打进 jar**，需单独目录供员工下载：

```bash
cd agent
VERSION=1.0.10 bash build-dist.sh
```

产物目录：

```text
agent/dist/install/
├── aiwatchd-darwin-arm64
├── aiwatchd-darwin-amd64
├── aiwatchd-linux-amd64
├── aiwatchd-windows-amd64.exe
├── aiwatchd.sh          # macOS / Linux 一键安装脚本
├── aiwatchd.ps1         # Windows 一键安装脚本
└── manifest.json        # 版本与 sha256（自更新用）
```

将整个 `install/` 目录上传到服务器，例如 `/srv/aiwatch/install/`。

## 6. 启动服务端（生产）

### 6.1 必改配置

编辑 `server/src/main/resources/application-prod.yml`，或在启动时用环境变量覆盖：


| 配置项                                       | 说明                                                         |
| ----------------------------------------- | ---------------------------------------------------------- |
| `server.port`                             | 监听端口（示例中为 `9527`，按实际修改）                                    |
| `spring.datasource.url`                   | JDBC 地址；`**characterEncoding` 必须为 `UTF-8**`（不能写 `utf8mb4`） |
| `spring.datasource.username` / `password` | 数据库账号                                                      |
| `aiwatch.install.dir`                     | 客户端分发目录绝对路径                                                |


### 6.2 启动命令示例

```bash
export DB_URL='jdbc:mysql://<db-host>:3306/am?useUnicode=true&characterEncoding=UTF-8&connectionCollation=utf8mb4_unicode_ci&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&rewriteBatchedStatements=true'
export DB_USERNAME=am
export DB_PASSWORD='<your-password>'
export AIWATCH_INSTALL_DIR=/srv/aiwatch/install

java -jar aiwatch-server-1.0.10.jar --spring.profiles.active=prod
```

### 6.3 首次登录

浏览器访问：

```text
http://<服务器地址>:<端口>/
```

`schema.sql` 预置默认账号（**部署后请立即修改**）：


| 项             | 默认值                                |
| ------------- | ---------------------------------- |
| 用户名           | `admin`                            |
| 密码            | `admin`                            |
| X-Admin-Token | `aiwatch-default-admin-token-0000` |


登录后进入 **系统设置 → 鉴权与安全**，修改密码与 Admin Token。

也可在 **系统设置** 各 Tab 配置 Judge 模型、定时任务、采集限额等（改完热生效，无需重启）。

## 7. 员工安装客户端

### 方式 A：登录页自助安装（推荐）

1. 管理员把后台地址发给员工，例如 `http://aiwatch.example.com:9527`
2. 打开登录页左侧 **「安装客户端」**，填写工号、姓名、部门
3. 选择 macOS / Windows / Linux，复制命令到终端执行
4. 脚本自动：下载二进制 → 注册 → 配置开机自启 → 启动上报

员工**无需登录后台**；若 `employee` 表无该工号，服务端会按姓名/部门自动创建记录。

### 方式 B：手动安装

```bash
# macOS / Linux
export AM_SERVER_URL='http://aiwatch.example.com:9527'
export AM_USER_CODE='SXF0001'
export AM_USER_NAME='张三'
export AM_USER_DEPARTMENT='研发部'   # 可选

/path/to/aiwatchd init
/path/to/aiwatchd start
```

Windows 使用 `install.ps1` 或安装包目录下的 `aiwatchd.exe init` / `start`。

### 安装后验证

```bash
aiwatchd status
```

日志路径（Windows 示例）：

```text
%LOCALAPPDATA%\aiwatchd\logs\aiwatchd.log
```

首次安装会进入 **bootstrap 回填**（扫描约 720 小时历史），属正常现象；稳定后每 5 秒上报一次。

## 9. 本地开发（可选）

适合二次开发人员本地调试：

```bash
# 1. 本地 MySQL 建库 am，dev 启动时会自动跑 schema.sql
cd server
./gradlew bootRun --args='--spring.profiles.active=dev'
# 默认端口 8081，见 application-dev.yml

# 2. 本地客户端分发目录（需先 build-dist）
cd agent && VERSION=dev bash build-dist.sh
# dev profile 默认指向 ~/projects/am/agent/dist/install
```

前端热更新（可选）：

```bash
cd server/src/main/frontend
pnpm install && pnpm dev
```

## 10. 常见问题

### JDBC 报错 `Unsupported character encoding 'utf8mb4'`

JDBC URL 里应写 `characterEncoding=UTF-8`，库表字符集用 `utf8mb4` + `connectionCollation=utf8mb4_unicode_ci`。

### 登录页能开，但登录一直转圈 / 超时

常见原因：大量员工**同时首次安装**，bootstrap 大包上报 + 后台会话审计占满数据库连接与 CPU。建议：

- 分批推广（例如每天 20～30 人）
- 首批 rollout 时临时关闭后台审计扫描：  
`--aiwatch.insight.audit-scan-enabled=false`
- 适当增大 `spring.datasource.hikari.maximum-pool-size`（需与 MySQL `max_connections` 匹配）

### 员工 Agent 连不上服务端

检查 `config.json` 里的 `server_url` 是否含**正确端口**（若未走 Nginx 反代，需带 `:9527` 等）。Agent 不读服务端 `server.port` 配置，只认安装时写入的完整 URL。

### 客户端分发目录未就绪

后台「安装客户端」会调 `/api/v1/install/status`。确保 `AIWATCH_INSTALL_DIR` 下存在四平台二进制和两个安装脚本。

### 升级客户端

服务端无需重启，重新 `build-dist.sh` 并覆盖 `install/` 目录即可；员工重启电脑或执行 `aiwatchd update` 会拉到新版本。

## 11. 交付清单（给外部团队）

建议一并提供：

1. 本仓库源码（或 release 包）
2. 已构建的 `aiwatch-server-*.jar`
3. `agent/dist/install/` 完整目录
4. 生产 MySQL 连接信息（或让对方自建库后跑 `schema.sql`）
5. 对外访问 URL（含端口或反代域名）
6. 初始管理员账号（并提醒首次登录改密）
