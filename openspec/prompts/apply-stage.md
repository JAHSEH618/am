# 单阶段实施 Prompt

适用方式：Cursor 中直接执行 OpenSpec 原生命令  
命令入口：`/opsx-apply`

```text
/opsx-apply
请按当前 change 的 tasks 只实施当前指定阶段，不要处理其他阶段内容。

本次实施阶段：
- <阶段名称>

实施范围：
- <本阶段允许修改的模块、文件、接口>

禁止事项：
- 不允许修改未授权模块
- 不允许顺手重构无关代码
- 不允许擅自调整接口语义或数据语义
- 不允许跳过测试补充
- 不允许处理下一个阶段任务

强制要求：
1. 实施前必须先读取 proposal、spec、design、tasks、testcases
2. 严格按 spec 和本阶段任务边界执行
3. 如发现文档与代码现状不一致，先指出差异，暂停实施
4. 实施完成后输出本阶段修改说明、风险说明、需要补充的测试点
```
